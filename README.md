# Electrical-Load-Forecast-of-the-LV-MDB

## Task: Electrical load forecast (kW) at each time step for the next 24 hours (h = z = 24 h) in hourly time resolution (Δt = 1 h).

## Motivation:
* Energy is a critical and costly production enabler; complex interdependent loads require balancing cost and reliability.
* Energy cost optimization requires accurate load forecasting
* Industry perspective: Forecasting allows scheduling, peak load management, and renewable integration for climate-neutral production.
